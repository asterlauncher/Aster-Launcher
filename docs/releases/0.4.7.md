# Aster Launcher 0.4.7 — Closed Alpha Foundation Update

The largest cumulative Aster Launcher update since 0.1.0.

Highlights include:

- Microsoft, Xbox, and Minecraft authentication with ownership checks.
- Real Vanilla, Fabric, and Forge instance launching.
- Modrinth and CurseForge discovery.
- Supported required dependency installation.
- Persistent downloads and installed states.
- Custom instance icons and modpack import/export.
- Live launcher presence and redesigned download and notification centers.
- Signed in-launcher updates with SHA-256 verification.
- Forge, export, Windows integration, layout, and background-process fixes.

Aster Launcher remains in closed alpha. Cosmetics, Aster Credits, and Aster
Subscription are previews and are not available for purchase.
