# Aster Launcher 0.6.0 — Multi-Game Foundation

Aster expands beyond Minecraft with its first complete game workspace for Sprocket.

## New

- Game switcher built into the existing Aster sidebar.
- Dedicated Sprocket home dashboard with Steam installation and build detection.
- Native Sprocket launch support with an Aster-managed portable mod runtime and safe mode.
- Local blueprint library with search, import and export.
- Community DLL mod management with Microsoft Defender scanning on import and before every modded launch.
- Safe blueprint tuning for recognized engine and weapon fields.
- Automatic safety copies before blueprint changes.
- Local Sprocket recovery vault and launch-time backups.
- Sprocket-specific launch and file-management settings.

Minecraft data and Sprocket data remain isolated. Aster downloads the official
MelonLoader x64 archive only from the LavaGang GitHub release, verifies GitHub's
SHA-256 asset digest, scans the archive and extracted runtime, and stores it in
Aster's private app-data directory. Only the required proxy bridge is activated
for a modded launch and removed after Sprocket exits. The managed runtime and
quarantine are removed by the Aster uninstaller. Aster never overwrites an
unknown game DLL and refuses to modify unknown blueprint fields.

MelonLoader is third-party open-source software licensed under Apache-2.0 and is
not developed or endorsed by Aster. Local antivirus scanning reduces risk but
cannot prove that any mod is completely safe.
