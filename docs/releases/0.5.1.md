# Aster Launcher 0.5.1 — Social Sharing & Public Build Fix

Version 0.5.1 prepares the social launcher for external testing.

- Choose an installed modpack directly inside a private conversation.
- Export and upload the pack automatically through Aster Social.
- Install received modpacks into My Modpacks with one click.
- Track shared-pack downloads in the launcher download center.
- Use Microsoft sign-in in public builds without local developer settings.
- Use Friends, chat, and presence from the public installer.

Shared content uses private storage and short-lived signed download URLs. This
is a closed-alpha build; Minecraft: Java Edition must be owned separately.
