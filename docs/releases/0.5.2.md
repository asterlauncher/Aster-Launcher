# Aster Launcher 0.5.2 — Social Reliability Hotfix

This local test build repairs the Aster Social connection flow before the next public release.

- Restores an existing valid Social session before applying sign-in cooldowns.
- Backs up Social sessions with Windows DPAPI so installer updates cannot lose them.
- Reduces duplicate profile heartbeats and database requests.
- Keeps underscores in Minecraft username searches.
- Adds a safe database search function with online-first results.
- Allows unused stale installer identities to be reclaimed without touching friendships or chats.
- Adds an in-place Retry action when the Friends page cannot connect.

The updated `supabase/social.sql` migration must be run once in the Supabase SQL editor for the full fix.
