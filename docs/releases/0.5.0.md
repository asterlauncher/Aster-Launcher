# Aster Launcher 0.5.0 — Aster Social

Version 0.5.0 introduces the first complete Aster Social foundation.

- Find Aster players by Minecraft username and send friend requests.
- Accept, decline, cancel, and remove social connections.
- See which friends currently have Aster Launcher open.
- Chat privately and share screenshots or modpack archives.
- Receive redesigned notifications for social and launcher activity.
- Configure updates, notifications, presence, motion, storage, privacy, and
  Minecraft memory in the redesigned Settings page.
- Recover signed launcher updates through GitHub Releases.

This is a closed-alpha build for public testing. Minecraft: Java Edition must
be owned separately. Cosmetics, Aster Credits, and Aster Subscription purchases
are not available yet.
