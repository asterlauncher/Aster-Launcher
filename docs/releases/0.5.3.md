# Aster Launcher 0.5.3 — Secure Social Session Hotfix

This patch publishes the fully repaired Aster Social connection flow without
overwriting the existing 0.5.2 release.

- Restores an existing valid Social session before applying sign-in cooldowns.
- Encrypts the Social session with Windows DPAPI.
- Preserves the same Social identity across launcher installer updates.
- Reduces duplicate profile heartbeats and database requests.
- Keeps underscores in Minecraft username searches.
- Uses safe online-first player search and stale empty-profile recovery.
- Adds an in-place Retry action when the Friends page cannot connect.

The updated `supabase/social.sql` migration must be run once in the Supabase
SQL editor for the complete server-side fix.
