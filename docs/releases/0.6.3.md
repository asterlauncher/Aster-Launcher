# Aster Launcher 0.6.3

This feedback build redesigns Bloons TD 6 mod handling around independent
modpacks.

- Community cards use a focused Manage action and no longer show approval,
  download, or file-size metadata.
- A target modpack is selected before importing or downloading a mod.
- The create flow matches the Minecraft modpack dialog and accepts a custom
  PNG, JPG, or WebP icon.
- Opening a modpack shows only its real, installed DLLs with scan and remove
  actions.
- Imported and downloaded DLLs stay disabled until that modpack is launched.
