# Aster Launcher 0.6.2

This build fixes persistent **another active Aster Social session** errors.

When a locally stored anonymous Supabase session is lost, the launcher can now
recover the inactive profile belonging to the same Minecraft UUID. Recovery
retains friends, requests, messages, Aster Credits, gifts, owner permissions,
Shared Worlds, and BTD6 community submissions. A second launcher that has sent
a profile heartbeat within the last two minutes remains protected.

The backend update is repeatable and is included in `supabase/social.sql` and
`supabase/social-session-recovery.sql`.
