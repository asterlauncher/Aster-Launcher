# Aster Launcher 0.4.8 — Closed Alpha Quality Update

Version 0.4.8 improves the closed-alpha launcher, distribution website, and
everyday update experience.

Minecraft version selection now includes the latest available releases and
keeps a current fallback list when Mojang's version service is unavailable.
Account data refreshes the active Minecraft skin automatically, stale update
progress is recovered correctly, and compact sorting controls now behave like
clear one-click actions.

The Aster website now follows the launcher design, includes the current
launcher preview and legal information, and serves the Windows installer
directly through its download route. The launcher continues to verify signed
update manifests and installer hashes before installing an update.

Aster Launcher remains in closed alpha. Cosmetics, Aster Credits, and the
Aster Subscription are previews and are not available for purchase yet.
